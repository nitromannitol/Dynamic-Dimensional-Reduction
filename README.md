# Dynamic-Dimensional-Reduction

A Lean 4 formalization of

> **Dynamic dimensional reduction in the Abelian sandpile**
> Ahmed Bou-Rabee

Every theorem, proposition, lemma and corollary of the paper is frozen as an
exact Lean statement with a line anchor into `paper/dimred.tex`, registered in
`ledger/manifest.yaml`, and then proved.  A node is `SEALED` only when its
proof compiles and its axiom closure contains no `sorryAx`.

The paper is entirely deterministic: the objects are the hypercube
`C_N^{(d)} ⊆ ℤ^d`, the parallel toppling odometer `v_t` and sandpile `s_t`, and
the sorted fundamental domain `S_M^{(d)}`.  `DimRed/Support/Basic.lean` fixes
that vocabulary; `DimRed/Frozen/` holds one frozen declaration per file.

